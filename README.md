# Hi there!
## This is a desktop video editor and recorder built using electron.js

### Steps to use it:
1. Clone the repo
2. `cd client`
3. Run `npm install` and then `npm run dev`
4. It will start the client side of the app at port 5173
5. For server, `cd server` and `node server.js`

### Features
1. Cut, Split, Trim
2. Record, edit and export using the same app
3. Auto-generate subtitles, add backgrounds, titlecards, lowerthirds
4. Integrated icon library
5. Trigger auto-zooms while recording, modify zoom level and position while editing
